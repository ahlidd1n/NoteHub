# 📝 NoteHub — Plan smarter, do more!

**NoteHub** — это современное и удобное Android-приложение для управления задачами и заметками, которое помогает планировать дела эффективнее и держать все важные задачи под контролем.

---

## ✨ Основные возможности

* 📊 **Наглядная статистика:** отслеживайте общее количество задач (**Total**), задачи в процессе (**Pending**) и выполненные дела (**Done**) прямо на главном экране.
* 🎯 **Система приоритетов:** назначайте каждой задаче уровень важности (**Low**, **Medium**, **High**) с цветовой индикацией и быстро фильтруйте список в одно касание (`All`, `Low`, `Medium`, `High`).
* 🔍 **Умный поиск:** мгновенно находите нужные заметки по названию или тексту через строку поиска (`Search tasks...`).
* ✏️ **Полное управление (CRUD):** удобное создание новых задач через всплывающее окно (`Create New Task`), редактирование, отметка о выполнении и удаление в один клик.

## 🛠 Технологический стек

* **Язык:** Kotlin
* **UI-фреймворк:** Jetpack Compose (Material Design 3)
* **Архитектура:** MVVM (Model-View-ViewModel)
* **Среда разработки:** Android Studio

---

## 📲 Скачать и установить

Готовый установочный `.apk` файл доступен в разделе **[Releases](https://github.com/ahlidd1n/NoteHub/releases)**:
1. Перейдите во вкладку **Releases** и скачайте последнюю версию `.apk` в блоке **Assets**.
2. Откройте файл на своем Android-смартфоне и подтвердите установку.
